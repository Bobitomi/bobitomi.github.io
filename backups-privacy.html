Backup privacy notice

This notice covers Relay Backups, the optional Google Drive connection used by Relay's operator. Updated 18 November 2026.

Data and purpose

Relay Backups stores encrypted database snapshots in the connected owner's private Drive folder for disaster recovery. A snapshot can contain company records, user profiles, team assignments, shifts, handovers, incidents, actions, chat history and stored authentication information. The snapshot is encrypted before upload; its decryption key is not uploaded with it.

The app uses Google's per-file drive.file permission. It creates the backup folder, reads folder and file metadata, lists backup copies and uploads missing encrypted files. It compares file sizes and checksums to confirm the copies. The owner or an authorized operator may download an encrypted file for a recovery test. The app does not request access to the whole Drive, Gmail or contacts.

Storage and protection

Google receives the encrypted file, filename, size, checksum and folder metadata. Relay's hosted server holds the Drive authorization needed to perform unattended uploads. A local setup copy of the credentials is encrypted under the operator's Windows account. Server settings, backup decryption keys and Google authorization credentials are kept out of the source repository.

The service records backup success or failure and timestamps for operations. It does not place database contents, access tokens or decryption keys in ordinary backup logs. An authorized recovery test decrypts a copy in an isolated location, checks it and removes the temporary restored database when the check ends.

Retention and control

Relay's hosted backup configuration keeps local snapshots for 30 days. Drive copies are retained until the owner removes them; automatic remote deletion is not enabled. The owner should review Drive storage and retention with their company. Removing a Drive copy does not remove the live company's records or other backup copies.

To stop future Drive access, remove Relay Backups from Google Account connections. Existing encrypted files remain in Drive until the owner deletes them. To request removal of stored authorization or help with company-record access, correction or deletion, contact the Relay operator at the support email shown on the Google consent screen. The company leader controls access to the company workspace.

Use and sharing

Backup data is used for storage, verification and authorized recovery. Relay Backups does not sell Google user data, use it for advertising, or use it to train AI models. Its use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

The backup connection is separate from Relay's Gmail sending connection. This public information site contains no company backup files.
